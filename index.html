1. 제품 / 상품 / 서비스 리서치
시장에 어떤 제품군이 있는지 파악하고, 나의 서비스가 들어갈 자리를 찾습니다.
왜 하는가?
서비스를 기획하기 전에 시장의 크기와 가능성을 먼저 파악해야 합니다. 아무리 좋은 아이디어라도 시장이 없으면 의미가 없고, 이미 포화된 시장이라면 차별점이 필요합니다.
무엇을 조사하는가?
제품군 선정
'OOO' 이란? 정의 내리기
시장 규모
국내/국외 규모와 전망
기업 선정
핵심가치와 비전 분석
관련 상품 리서치
유사 서비스 4~5개 비교
어떻게 하는가?
1
제품군 정의 — 내가 만들 서비스가 속하는 카테고리를 명확히
2
시장 규모 조사 — 통계 자료, 뉴스, 리포트 활용
3
기업/브랜드 선정 — 핵심가치와 고객 가치 정리
4
관련 상품 조사 — 사진, 기업, 종류, 기능, 출처 비교표
TIP: 나의 포지션을 정해보세요!
ex) 휴먼포커서 / 키 펑셔너 / 유저 센터드 테스터

PEST 분석
정치·경제·사회·기술 4가지 거시 환경 요인을 분석하여
서비스가 놓일 시장 환경을 객관적으로 파악합니다.

Phase 1 — 시장 분석
2. PEST 분석
거시 환경 분석을 통해 외부 요인이 서비스에 미치는 영향을 파악합니다.
PEST란?
기업 외부의 거시적 환경 요인을 4가지 관점에서 분석하는 프레임워크입니다. 서비스가 놓일 환경을 객관적으로 이해하는 데 필수적입니다.
P
Political (정치)
정책, 규제, 지원 제도
E
Economic (경제)
매출, 소비 패턴, 시장 성장
S
Social (사회)
트렌드, 문화, 라이프스타일
T
Technological (기술)
신기술, 플랫폼, 인프라
작성 방법
1
각 영역별 Keyword를 정합니다
2
관련 사진 + 상세 설명을 작성합니다
스터디하는 느낌으로, 최대한 구체적으로!
3
관련 링크/출처를 첨부합니다
4
Keyword Summary 3개 버블로 정리합니다
5
각 영역의 Insight를 도출합니다
TIP: 4개 영역의 Insight를 종합하는 PEST Summary 다이어그램을 마지막에 만들면 전체 흐름이 보입니다.

SWOT 분석
내부 강점·약점과 외부 기회·위협을 교차 분석하여
실행 가능한 4가지 전략을 수립합니다.
이론예시워크북
Phase 1 — 시장 분석
4. SWOT 분석
자사(또는 나의 서비스)의 내부 역량과 외부 환경을 교차 분석합니다.
SWOT란?
내부의 강점(S)·약점(W)과 외부의 기회(O)·위협(T)을 파악한 뒤, 교차 조합하여 4가지 전략을 도출하는 프레임워크입니다.
S
Strength (강점)
내부 + 긍정적 요인
W
Weakness (약점)
내부 + 부정적 요인
O
Opportunity (기회)
외부 + 긍정적 요인
T
Threat (위협)
외부 + 부정적 요인
SWOT Strategy (교차 전략)
SWOT 4요소를 교차 조합하여 실행 가능한 전략을 수립합니다.
SO 전략
강점으로 기회를 살린다
ST 전략
강점으로 위협을 방어한다
WO 전략
약점을 보완해 기회를 잡는다
WT 전략
약점과 위협을 최소화한다
TIP: S·W는 내가 바꿀 수 있지만, O·T는 바꿀 수 없는 외부 요인입니다. PEST 분석 결과를 O·T에 반영하면 일관성이 높아집니다.

SWOT 분석 — YAKEY 야구 팬덤 앱
S 강점
• 야구+팬덤 결합 앱 없음
• 20대 여성 타겟 명확
• 입문자 친화 설계

• 콘텐츠 자체 제작 부담

• 정부 스포츠 관람 지원
T 위협
• 구단 공식 앱 경쟁
• 대형 팬덤 플랫폼 진입 가능
• 시즌 비수기 사용률 저하

SWOT Strategy
SO 전략
야구 팬덤 결합 앱이라는 유일한 포지션 + 1000만 관중 시대를 활용해 → 입문자 전용 팬덤 플랫폼으로 포지셔닝
ST 전략
구단 공식 앱과 차별화하여 → 커뮤니티·굿즈·콘텐츠 중심으로 경쟁 회피
WO 전략
SNS 바이럴 + 팬덤 문화 활용하여 → 초기 사용자 빠르게 확보
WT 전략
비수기에도 유지될 수 있는 → 팬 커뮤니티·아카이브 콘텐츠 확보

5. 설문조사 (정량 조사)
많은 사람들의 의견을 수치화하여 시장과 사용자의 특성을 파악합니다.
정량 조사란?
숫자로 표현할 수 있는 데이터를 수집하여 객관적인 근거를 마련합니다. 주관적 판단이 아닌, 통계적으로 사용자 니즈를 파악할 수 있습니다.
설문 설계 3단계 퍼널
1
Basic Information
나이, 성별, 직업 등 기본 정보
2
Lifestyle
생활 패턴, 관심사, 활동 관련
3
Product / Service
서비스 관련 구체적인 질문
설문 작성 TIP
1. 넓은 것 → 좁은 것
일반적인 질문에서 구체적인 질문으로 자연스럽게 좁혀가세요

2. 40명 이상 확보
통계적으로 의미 있는 표본을 확보해야 합니다

3. 응답 형태 다양화
객관식 / 주관식 / 리커트 5점 척도 / 복수 선택 등

4. 중립적 질문
"이 앱이 좋으시죠?" ✗ → "이 앱에 대해 어떻게 생각하시나요?" ✓

Phase 3 — 구체화
고객 여정 지도 (Customer Journey Map)
사용자가 서비스를 경험하는 전 과정을 시각화하여 문제점과 기회를 발견합니다.
여정 지도란?
사용자가 서비스를 인지 → 사용 → 종료하는 전체 경험을 시간 순서대로 나열하고, 각 단계에서의 행동·감정·문제점·니즈를 한눈에 파악합니다.
구성 요소
1
단계 (Stage)
인지 → 탐색 → 사용 → 재방문
2
터치포인트
사용자가 서비스와 만나는 접점
3
행동 & 감정
무엇을 하는지 + 기분 변화 곡선
4
문제점 → 니즈 → 해결방안
Pain Point에서 기능 아이디어 도출
작성 순서
1
단계 정의 — 서비스 경험의 시간순 단계 나열
2
터치포인트 배치 — 각 단계에서 만나는 채널/화면
3
행동 기술 — 사용자가 실제로 하는 행위
4
감정 곡선 — 기쁨/불편/좌절 등 감정 변화 그래프
5
문제점 → 니즈 → 해결방안 — Pain Point 기반 기능 도출
TIP: 감정 곡선이 가장 낮은 지점이 가장 큰 기회입니다. 그 지점의 문제를 해결하면 서비스의 핵심 가치가 됩니다.

8. 페르소나 설정
조사 결과를 기반으로 가상의 대표 사용자를 구체적으로 만듭니다.
페르소나란?
리서치 결과에서 도출된 핵심 타겟의 대표 인물을 상세하게 묘사합니다. 실제 사람처럼 구체적으로 만들어야 "이 사람을 위한 서비스"라는 관점이 생깁니다.
페르소나 구성 요소
인구통계
이름, 나이, 성별, 직업, 성격
행동
현재 행동 패턴과 습관
상황
서비스를 필요로 하는 맥락
목표
서비스를 통해 달성하고 싶은 것
좋은 페르소나의 특징
1. 데이터 기반 — 상상이 아닌 리서치 결과에서 도출
2. 구체적 — "20대 여성" ✗ → "박채윤, 21세, 대구대 재학중" ✓
3. 공감 가능 — 팀 전체가 "이 사람을 위해 만든다"는 관점 공유
4. 기능 도출 가능 — 페르소나의 필요에서 기능 요구사항이 나옴
TIP: 페르소나 카드는 4가지(행동/상황/목표/기능) 영역으로 나누어 작성합니다.
각 카드가 설문/인터뷰 데이터와 연결되어야 설득력 있습니다.

Phase 3 — 구체화
10. IA / 사이트맵 / 플로우차트
서비스의 구조를 설계하고, 사용자의 이동 경로를 정의합니다.
IA (Information Architecture)
서비스의 정보 구조를 계층적으로 설계합니다. 사용자가 원하는 정보를 최소 탭 수로 도달할 수 있도록 Depth를 설계합니다.
Depth 비유: 곰인형 = 전체 서비스
Depth 1 (팔, 다리) → Depth 2 (손가락) → Depth 3 (손톱) ...
너무 깊으면 사용자가 길을 잃습니다!
사이트맵
IA를 시각적으로 표현한 전체 구조도. 메인 메뉴 → 서브 메뉴 → 상세 페이지 순으로 트리 형태로 나타냅니다.
플로우차트
사용자가 서비스 내에서 특정 목표를 달성하기 위한 경로를 시각화합니다.
1
주요 시나리오 선정 — 핵심 사용 흐름 2~3개
2
시작 ~ 종료 지점 — 진입점과 완료 조건 정의
3
분기점 표시 — 조건에 따른 경로 분기 (Yes/No)
4
화면 단위로 표현 — 각 화면 이름 + 주요 액션
IA → 사이트맵 → 플로우차트 순서로 작업하면 구조가 탄탄해집니다.
